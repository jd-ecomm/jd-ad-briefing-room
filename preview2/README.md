# /preview2/: Creative Discovery inside the Briefing Room (built on /discovery/)

The /discovery/ app moved into the Briefing Room, with only the changes Ryan asked for (8 and 9 Nov 2026). The live root pages and /discovery/ are unchanged.

- `preview2/index.html` is the root `index.html` with `<base href="../">` (live `brief.js`, `data.json`, fonts, studio images), a small patch that keeps hash links on `/preview2/`, `trending.js` and `inspo.js` removed, and `preview2/cd-app.js` added.
- `preview2/cd-app.js` / `preview2/cd-app.css` are copies of `discovery/discovery.js` / `discovery.css`, rendered into a shadow root on `<section id="v-cd">` so the two style sheets never mix. Entry: the Creative Discovery button in the Projects row ("Always on"), where Discover Ads was. Projects and every other section are untouched.
- Kept from /discovery/: Directory (was Home), Discover library with natural-language search, sorts and densities, ad viewer (Reels, Stories, Feed, Proven score, hook timeline, key frames, concept variants, more like this), brand pages, compare, boards, Reels mode, keyboard shortcuts, deep links `#ad/<id>`.
- Changed: sub tabs Directory, Discover, JD, Trending, Brands, Boards, Reels under the Briefing Room header (no own header, no bottom tab bar); "Directory" instead of "Home"; Filters panel (button, grouped chips with live counts, active chips row); "Loading creative" loader on every creative; cards never cropped (true aspect, object-fit contain, masonry columns); videos play on hover only, no scrubbing, Autoplay button (off by default, remembered) to play in view; JD tab = the JD Global view (KPIs, market chips, formats they lean on, Proven score, tags) as a 2-column grid with bigger creatives; Trending = Runneth tr_ads as native cards with a rank badge; viewer video has native controls, the hook timeline is display only; hook labels: Hook line = hook_text, On-screen text = onscreen_text, Meta headline labelled as such, fallback "No on-screen text (visual hook)", never the Meta headline; no made-up like or comment numbers.
- Data: Supabase `in_ads` (batch is not null, English, plus hook_text, onscreen_text, hook_kind), `tr_ads`, `in_favs`, `in_boards`, `in_board_items`. Pages are retried when the database is busy.
- Check: `.github/workflows/cd-preview-check.yml` runs `tools/cd-preview-check.js` in Chrome at 1440x900 and 390x844 against the deployed page and pushes screenshots to `cd-preview-shots/run-<id>`. Offline: `node tools/cd-preview-check.js http://localhost:8000/ out --fixture <media dir>` (ONLY=1440 or ONLY=390 for one size).

To go live: in the root `index.html`, swap `trending.js` + `inspo.js` for `preview2/cd-app.js` (plus the Sortable script and the small `#v-cd` style block from `preview2/index.html`).
